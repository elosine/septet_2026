# septet 2026

A composition for flute (piccolo, bass flute), bass clarinet, piano, violin 1, violin 2,
viola and cello, written for the TEMPUS LAB 2026 call for scores (Leipzig, deadline
2026-10-15). Piece #5 in the composer's custom-composition-system lineage; the software
is ported from `for_seven_tubas` (piece #4).

Orientation for any AI session: `CLAUDE.md`, then `docs/PROJECT_JOURNAL.md` §2.
